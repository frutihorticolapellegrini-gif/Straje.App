# REGLAS OBLIGATORIAS DE DESARROLLO (ANTIGRAVITY)

1. **EJECUCIÓN PUNTO POR PUNTO:** Trabajá **exclusivamente** en el punto que te indique el usuario. Al terminar ese punto, detenete, resumí brevemente qué archivos modificaste y **preguntá explícitamente** antes de avanzar al siguiente.
2. **PROTECCIÓN DE DATOS Y MULTIMEDIA:** Prohibido modificar esquemas de base de datos productivos, borrar registros o alterar almacenamiento de videos/archivos cargados por usuarios. La app está en producción con usuarios activos.
3. **DISEÑO RESPONSIVE INTACTO:** No rompas ni alteres las media queries, grillas o layouts adaptativos (móvil, tablet y PC) que ya funcionan correctamente. Cualquier elemento nuevo debe respetar la línea visual actual, sumando colores y detalles atractivos sin desacomodar vistas existentes.
4. **ALCANCE ESTRICTO:** No toques archivos, rutas ni funcionalidades que no estén explícitamente mencionados en el punto actual.
5. **AHORRO DE TOKENS Y EFICIENCIA:** No reescribas archivos completos si solo necesitás modificar un bloque específico. No agregues librerías pesadas ni dependencias innecesarias. Mantené el código limpio, modular y directo.
